Stickyverse

App / UI

Stickyverse verandert je Windows- of macOS-bureaublad in een muur vol sticky notes. Notities, taken, herinneringen en projecten blijven in zicht terwijl je werkt. Het design, de interface en de ontwikkeling heb ik zelf gedaan.

Starry Tako

Packaging / mascotte / web

Starry Tako is mijn kleurrijke verpakkingsconcept voor koekjes van OOGBITES. Ik ontwierp de mascotte, de verpakking en de website voor kinderen die gefascineerd zijn door de ruimte en technologie.

IMERS

Branding / motion / web

IMERS is een fictief brandingproject voor het MSK Gent dat jonge creatievelingen op een eigentijdse manier kennis laat maken met klassieke kunst. Het doel: een creatief, meeslepend merk, geïnspireerd op de middeleeuwse schilderijen van het museum, dat tot leven komt in affiches, animaties en webdesign.

Para Ti

Visuele identiteit

Para Ti is een kleine geautomatiseerde buurtwinkel waar je verse, lokale producten koopt. Om het merk een glow-up te geven, ontwierp ik een volledig nieuwe visuele identiteit: logo, kleurenpalet, visitekaartje, typografie en socialemedia-visuals, die de warme buurtsfeer rond hun winkels blijft uitstralen.
